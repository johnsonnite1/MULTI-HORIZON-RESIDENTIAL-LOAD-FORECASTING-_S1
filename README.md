# Supplementary Material S1

## Multi-Horizon Residential Load Forecasting Using Coherent Conformal Hierarchical Stacking

This archive accompanies manuscript OJEIT-0202-02. It contains the de-identified one-minute household record, the end-to-end analysis script, dependency versions, numerical result files, test predictions, and generated analytical figures.

## Contents

- `reproducibility/data/raw/residential_energy_1min.csv`: 129,600 consecutive one-minute records.
- `reproducibility/data/metadata/source_manifest.json`: source-file metadata.
- `reproducibility/src/run_experiments.py`: complete analysis pipeline.
- `reproducibility/requirements.txt`: tested Python dependency versions.
- `reproducibility/results/`: data audit, split manifest, metrics, test predictions, and summary.
- `reproducibility/figures/`: analytical figures regenerated by the script.

## Reproduce the analysis

From the archive root, run:

```bash
python -m pip install -r reproducibility/requirements.txt
python reproducibility/src/run_experiments.py
```

The script uses random seed `20260824`. Chronological train, validation, calibration, and test boundaries are written to `reproducibility/results/split_manifest.csv`.

## Data and scope notes

- The record covers 1 December 2025 through 28 February 2026 for one de-identified household in Ota, Ogun State, Nigeria.
- `Total_Power` equals the sum of Fan, PC, AC, Lamp, and TV to numerical tolerance.
- Every appliance value is strictly positive, so the data do not support appliance on/off-state or usage-duration claims.
- The raw CSV header does not encode a physical unit. The analysis provisionally treats each value as interval energy in kWh per one-minute record; 15-minute sums are divided by 0.25 h to obtain mean kW. If the meter export uses another unit, the physical-unit labels require rescaling.
- The acquisition hardware served only to export the model-input series. Sensor-level current/voltage-module metrology is outside the forecasting experiment and is not represented as a validated contribution in this archive.
- The results are a single-household case study and should not be generalised to Nigerian households as a population.

## Main interpretation

CCHS provides competitive point accuracy, exact appliance-to-total coherence, and empirically assessed conformal prediction intervals. Its gain over the best individual learner is below 1%. Nominal 90% intervals are near nominal marginally, while lower worst-regime coverage documents remaining conditional undercoverage.
